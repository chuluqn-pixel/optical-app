# Optical ERP

## Project Overview

Optical ERP adalah aplikasi berbasis web yang dirancang untuk mengelola seluruh operasional toko optik mulai dari master data, inventori, penjualan, pembayaran, angsuran, hingga laporan.

---

## Goals

- Multi Cabang
- Multi User
- Role Based Access
- Inventory Management
- Sales Management
- Installment Payment
- Customer History
- Eye Prescription
- Reporting Dashboard
